### Abdul Al Mamun

Applied AI engineer and researcher in Dhaka, Bangladesh. I work on **efficient AI for limited compute**:
lightweight vision models for crop-disease detection, and agents and evidence-grounded RAG on self-hosted open-weight LLMs.

**Selected work**
- [csxai-crop-disease](https://github.com/a-a-mamun-rm/csxai-crop-disease): ~0.4M-parameter (1.5 MB) CNN-SVM crop-disease model with Grad-CAM, 99.09% accuracy. *Frontiers in Plant Science* 2024 ([paper](https://doi.org/10.3389/fpls.2024.1412988))
- [legal-document-intelligence](https://github.com/a-a-mamun-rm/legal-document-intelligence): OCR extraction, hybrid dense + BM25 retrieval (MRR 0.938, small 8-query set) and grounded drafting with evidence citations
- [llm-email-eval-harness](https://github.com/a-a-mamun-rm/llm-email-eval-harness): provider-agnostic LLM generation with a custom-metric evaluation harness and baseline-vs-advanced prompt comparison

**Industry:** served open-weight LLMs with vLLM (tensor and pipeline parallelism) and built agent, RAG and document pipelines at Betopia (code private).

**Interests:** efficient AI for agriculture · efficient LLM inference and agents · trustworthy LLMs (grounding, abstention)
